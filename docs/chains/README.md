# Chain pages

One page per source chain that this branch verifies into Hiero. Each page lists the chain's quick
facts, its exact deployment profile, what a relayer needs, chain-specific caveats and how the live data
was verified. The design, trust model and proof format of the verifier family are in the family README:
[Stellar verifier (`StellarScpVerifier`)](../../src/verifiers/evm/stellar/README.md).
